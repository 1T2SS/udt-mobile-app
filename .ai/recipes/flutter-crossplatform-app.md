# Recipe: Flutter Cross-Platform Mobile App (Riverpod + GoRouter)

## When to Use
Use this recipe when building a high-FPS custom UI mobile app across iOS, Android, and Desktop using Flutter & Dart.

## 1. Official Scaffold Commands
```powershell
flutter create . --org com.example
flutter pub add flutter_riverpod go_router shared_preferences
```

## 2. Verification Commands
- **Environment Check**: `flutter doctor`
- **Static Analysis**: `flutter analyze`
- **Unit & Widget Tests**: `flutter test`
